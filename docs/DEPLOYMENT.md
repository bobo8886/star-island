# 部署与分享教程

[返回首页](../README.md) · [怎么玩](USER_GUIDE.md) · [修改信息](CUSTOMIZATION.md) · [开发维护](DEVELOPMENT.md)

本项目是静态 H5 游戏。运行游戏不需要账号、数据库或后端服务。公开示例地址是：

**https://bobo8886.github.io/star-island-time-capsule/**

## 1. 先分清你要分享什么

| 目标 | 应该交给朋友的内容 |
| --- | --- |
| 让朋友体验通用模板 | 上面的在线试玩链接 |
| 送一份自己修改过的完整生日游戏 | 礼物工坊导出的专属 HTML，或用它发布的网址 |
| 只送许愿树下写的小信 | 写信页生成的 PNG 图片，长信逐页保存 |
| 在另一台设备继续自己的进度 | 设置里导出的「时光备份」JSON |
| 让别人继续开发游戏 | 仓库链接或完整项目 ZIP |

工坊里按保存会写入当前浏览器存档，不会修改 GitHub 仓库，也不会改变公开试玩页的默认内容。要分享自己的版本，先导出专属礼物。

## 2. 最快的方法：发送单个 HTML 文件

1. 打开游戏，在工坊完成内容编辑。
2. 点击「保存这份心意」，再点「导出礼物」。在设置页也可以使用「导出专属礼物 HTML」。
3. 浏览器会下载 `给某某的星屿.html`，其中包含文案、图片、语音与游戏本体。
4. 自己先在浏览器里打开这份下载文件，检查称呼、回忆和长信是否正确。
5. 把下载文件作为文件发给朋友。对方保存到设备后，用浏览器打开。

通用离线文件 `星屿寻迹.html` 约 45 MiB，定制照片和语音会继续增加体积。聊天软件的文件预览器不一定执行 HTML；手机使用下面的网页链接方案通常更方便。不要把 GitHub 的代码预览页当作游戏网页。

## 3. 发布本仓库：GitHub Pages

本仓库首页是根目录的 `index.html`，它读取旁边的 `src/`、`assets/` 和三份 CSS。根目录还保留 `星屿寻迹.html`，用于离线下载及工坊导出模板。

自己 Fork 或复制这个仓库后，可以这样启用 Pages：

1. 进入你自己的仓库，打开 **Settings → Pages**。
2. 在 **Build and deployment → Source** 选择 **Deploy from a branch**。
3. 分支选 **main**，文件夹选 **/(root)**，点击 **Save**。
4. 等待仓库的 Pages 构建完成；可以在 **Actions** 查看 `pages build and deployment` 的状态。
5. 回到 Pages 设置页，打开它显示的网址。

网址通常是 `https://你的GitHub用户名.github.io/仓库名/`。本项目的资源使用相对路径，可以运行在仓库子路径下；`.nojekyll` 让静态文件直接发布。分支与发布目录设置以 [GitHub 官方 Pages 文档](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site) 为准。

**更新页面**：修改源码后重新运行 `npm run build`，提交并推送 `main`，Pages 会发布新的分支内容。等待构建成功后再刷新。浏览器已有存档可能继续显示你以前保存的称呼，这是本机内容覆盖默认模板；可用新的浏览器配置检查出厂模板。

## 4. 给某个人发布一个定制网址

这一步使用「导出的专属礼物」，而不是把本机存档直接复制到 GitHub。

1. 在工坊导出专属 HTML，并确认内容。
2. 为这份礼物准备一个独立静态站点或新仓库。
3. 把导出的 HTML 重命名为 `index.html`，放在该站点的发布根目录。
4. 使用静态托管发布；如果是 GitHub Pages，按上一节选择包含这个文件的分支和根目录。
5. 在另一个浏览器配置或设备打开新网址，确认收礼人从零开始探索。
6. 把这个新网址发给收礼人。

专属 HTML 已内嵌素材，不需要再复制 `src` 和 `assets`。公开网页中的祝福、照片和语音也会随文件公开，因此应选择自己愿意公开的内容；只想私下交付时，可直接发送 HTML 文件或 PNG 信件。

不要用一次性的私人礼物覆盖本项目通用源码的 `index.html`：为具体收礼人单独发布，更便于以后维护通用模板。

## 5. 发许愿树的小信到微信

1. 在许愿树旁按 F，填写称呼、署名、标题、日期和正文。
2. 选择信纸，点击「生成信件图片」。
3. 点击「下载第 N 页 PNG」；手机也可以长按预览中的真实图片保存。
4. 长信有多页时，逐页切换并保存。
5. 打开微信聊天，从相册选择保存的图片发送。

若浏览器支持文件分享，会出现「系统分享」，由你选择应用和联系人；项目不会自动向任何联系人发送。系统分享菜单中是否包含微信，取决于设备和浏览器。保存 PNG 后手动发送无需依赖这个按钮。

## 6. 在同一 Wi-Fi 下给手机预览

电脑安装 Node.js 后，在项目根目录执行：

```sh
node server.js --host 0.0.0.0
```

查到电脑的局域网 IPv4 地址，例如 `192.168.1.20`，在同一 Wi-Fi 下的手机浏览器打开 `http://192.168.1.20:4173/`。这里的地址是示例，请换成你自己的电脑地址。

手机里的 `127.0.0.1` 指向手机本身，不能拿它访问电脑。若连不上，检查两台设备是否在同一局域网，以及电脑防火墙是否允许 Node.js 的本地访问。此方式只用于同网段预览，不是公网部署。

## 7. 常见问题

| 现象 | 处理方法 |
| --- | --- |
| Pages 显示 404 | 确认分支是 main、目录是根目录、根目录有 index.html，再查看 Pages 构建状态 |
| 打开的是 HTML 源码 | 你在 GitHub 文件预览页；改用 Pages 网址或下载后用浏览器打开 |
| 我改了信息，朋友打开还是模板 | 你只保存了本机数据；重新导出专属礼物，再发送文件或发布它 |
| 朋友看到自己的进度，另一台设备没有 | 进度按浏览器设备保存；用时光备份迁移，没有云同步 |
| 照片、声音不见了 | 确认工坊已保存，并把最新导出的专属礼物发出去，而非原模板 |
| 更新后页面看起来没变 | 等 Pages 构建完成后重新载入；另用新浏览器配置检查默认内容 |
| 手机文件预览空白 | 改用正常浏览器打开，或发布成 HTTPS 链接 |
| 系统分享不可用 | 下载 PNG，在微信相册手动选择发送 |
