# 交互地点标记

`src/waypoints.js` 提供 `new IslandWaypoints(world)`。世界绘制结束后调用 `draw(ctx)`，内部切换到 CSS 屏幕坐标；`hitTest(x,y)` 返回原始交互物件，交由 `world.go(item,item)` 寻路；`snapshot()` 提供布局与命中区域用于验收。构造阶段不依赖画布尺寸。

- 当前区域 `world.items` 的全部类型参与标记，编号使用数组原顺序加一，与岛屿地图清单一致。名称直接读取物件的自定义 `name/theme`，不复制剧情或人物资料。
- 地面定位圈、数字圆牌、连接线和名牌分别明确物件位置与名称。出口使用奶油色方向牌，优先寻找可用位置；附近显示 F 或触控提示，已发现物件保留勾选和重读/再玩状态。
- 字号保持桌面 12 CSS 像素、手机 11 CSS 像素，不随世界缩放改变。标签避让人物、HUD、生日烟花文字和其它标签。手机拥挤时使用紧凑编号与最多两行的可点击附近名单；完整点位可在岛屿地图查看。
- 不把屏外坐标夹到屏幕边缘；被 HUD 实际遮住的物件不显示漂移标记。未开始、暂停、加载、活动特写和拍照时隐藏，拍照成品不会带地点牌。
- 标记没有周期闪动或摇摆，减少动态模式使用同一静止布局。HUD 的布局测量每 300 毫秒最多一次；长名称使用二分截断。

验证入口：`node tests/waypoints.cjs` 和 `python tests/waypoints-world.py`。后者需要本地服务 `http://127.0.0.1:4173` 与 Playwright 的 Edge，覆盖四区、1440×900 / 390×844 / 375×667 / 844×390、DPR 2、0.7 / 1.6 缩放、剧情真实点击与手机出口跨区。截图与报告位于 `output/waypoints/`。
