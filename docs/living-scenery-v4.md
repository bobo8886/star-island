# 会呼吸的星屿 · 场景动画

`src/scenery.js` 根据已有三张原创插画的真实坐标绘制动态层，不修改导航和碰撞。

## 内容

- 主岛：主河道与桥下游方向性流水，两段向下流动的瀑布与水雾，码头水波；62 片有远近、翻面、侧风和消散变化的粉色花叶。触碰许愿树额外扬起 28 片花叶，树下行走带起少量落叶。
- 花田：池塘折射与扩散涟漪，43 片金绿树叶，12 只蝴蝶，凉亭风铃和各处暖灯。
- 海岸：海水纹理扰动、两段沿岸推进的波浪与泡沫、水花，灯塔渐隐光束和轻摆的海风铃。
- 三图的拾取和交互都有局部粒子反馈。切换地图清空前一地图的临时粒子。

## 渲染与性能

接口为 `new IslandScenery(world)`，`draw(ctx,time,'ground'|'air')`、`react(item)`、`step(player)`。

第一次进入区域时，将图中的水色和白色泡沫从预先标定的水域轮廓提取为透明纹理。每帧只执行小幅分条折射和泡沫绘制，再套用原水色蒙版，避免海浪越过岩石、码头或桥面。水纹、灯光渐变和叶片小图预先缓存，逐帧不读取像素。临时反馈粒子最多 128 个。

「减少动态效果」关闭所有运动层与新反应粒子，保留静态环境和灯光；离屏对比不同时刻的结果完全一致。

`tests/scenery-v4.py` 使用实际浏览器 Canvas 校验：三图水域和空气层确实发生变化，主岛桥面不受水纹覆盖，减少动态时变化像素为 0，逐帧读回次数不增加。结果见 `output/scenery-v4-report.json`；三图检查画面为 `output/scenery-*-v4.png`。

该模块 CPU 提交成本在一次 Edge 无头、1536 × 1024 离屏测试中约为主岛 0.4 ms、花田 0.18 ms、海岸 0.26 ms。这是附加动态层的 CPU 时间，不是 GPU 帧率或手机性能保证。
