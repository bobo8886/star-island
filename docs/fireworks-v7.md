# 持续生日烟花（v7）

`src/fireworks.js` 提供 `IslandFireworks(world)`。主循环调用 `update(dt)`；背景层在地图底图之后、道具和人物之前调用 `draw(ctx,'sky')`，文字层在世界绘制之后调用 `draw(ctx,'text')`。两层都使用已经设置 DPR 的屏幕 CSS 坐标。`replay()` 从发射阶段重播；`snapshot()` 返回时间、主题、活动粒子、缓存与布局信息。构造函数不依赖已经完成 resize。

只有 `world.started && world.state.finished` 时启用。完成存档刷新后自行启动；切图保持七秒周期并切换配色、清除旧区域余火；重开后自动清空。没有独立计时器、requestAnimationFrame 或事件监听。`document.hidden` 时不积时；对话暂停并不冻结环境。`draw()` 不推进时间或粒子，拍照只是以照片尺寸重绘同一时刻。

每七秒一轮，有四次上升尾迹与不同图案的绽放。主岛采用桃金爱心和星形，森林采用紫绿花形，海岸采用蓝金星形与潮环，湖谷采用月蓝莲形。火花在开场汇聚成大字，清晰光芯约亮三秒，随后散成下落余辉。文字读取 `IslandPersonalization.text('ending.fireworkText')`，缺失时为 `生日快乐!`。个性化长文字自动换行、缩字；最多接收 64 个字符作为防御性绘制界限，编辑器应使用适合庆典短句的长度。

辉光与锐利光芯合并缓存；图案余辉也离屏缓存。动态粒子上限 560，火箭最多 5，图案余辉最多 8，字形点最多 280；字形布局缓存最多 4，图案缓存最多 16，配色辉光最多 12。只在构建字形时采样一次像素，不在帧循环中读回画布。文字布局避开顶栏、手记和实际地区条 `#world-label`；照片不复用网页 HUD 的位置。桌面地区条高 38、顶部 109 时，文字布局顶部为 165，保留 18 像素间距；harness 包含这个真实 ID 的回归断言。

横屏以 `height <= 540 && width > height` 判定。祝福限制在人物中央区域右侧，右边距 24；默认短句仍用大字，长句在该窄区域内换行与缩字。844×390 和 844×500 的默认字号为 52，文字 x=593.87–820，连同 32 像素余辉也避开 x=454.39–558.39 的人物保护区。测试同时覆盖 960×540 边界与横屏长祝福，防止再次遮住女主面部。

减少动态模式清空发射物和余火，停止庆典时钟，仅保留静态祝福和少量星光；不会留下闪烁的旧粒子。

## 独立自检

运行 `python tests/fireworks-v7.py`。证据保存到 `output/fireworks-v7/`，包括四区画面、0.4/0.8/1.35/3.9/5.15/7.4 秒周期帧、四个屏幕尺寸、静态模式与个性化文字。

测试使用临时浏览器文档和独立 world，不接触真实玩家档案。覆盖未解锁关闭、完成档恢复、七秒循环、五分钟 60 Hz 模拟、切图配色、重播、重开、再次恢复、可编辑文字、绘图/拍照不推进、减少动态像素一致，以及 390×844、375×667、844×390、844×500、960×540、1440×900 的 HUD 避让。隐藏页验证通过受控 `document.hidden` 执行真实守卫，并不声称在无头浏览器验证了系统原生后台调度。

当前五分钟模拟为 42 轮，活动粒子峰值 232；240 帧监测无逐帧像素读回；浏览器异常为 0。为了严格比较静态像素，harness 主画布使用 `willReadFrequently`，其绘制耗时是软件读回兼容画布的局部成本，不代表完整游戏 FPS。实际游戏、离线包和最终 HUD 组合另由集成回归验证。

已打开并目测四区、横竖屏与周期截图：文字清楚，发射/汇聚/散去分段可见；爱心和星形在暗天空最清楚，花形使用较轻的图案余辉以适应明亮植被。背景烟花绘在人物后面，不对人物轮廓施加额外闪白或抖屏。
