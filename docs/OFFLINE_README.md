# 星屿寻迹 · 离线玩家包

## 开始游玩

1. 将下载的 ZIP 完整解压到文件夹。
2. 用 Edge、Chrome 等浏览器打开 `星屿寻迹.html`。
3. 等待素材加载完成，点击「开启这场奇遇」。

游戏、地图、角色和声音已打包进这一个 HTML，无需安装 Node.js 或 Python。
手机的文件预览器不一定运行 HTML；手机优先使用正常浏览器或在线试玩。

- 电脑：WASD / 方向键移动，F 交互，Shift 快走，空格跳跃，M 地图，J 手记。
- 手机：左下摇杆移动，右下互动、快走和跳跃。
- 主线：收集五枚记忆水晶，到观星台按「初遇 → 相知 → 日常 → 和好 → 未来」连星，打开生日盲盒。
- 许愿树：可随时写信、保存草稿、生成高清 PNG，然后从微信相册发送。

## 制作自己的生日礼物

欢迎页点「制作一份专属礼物」，或从设置打开礼物工坊。编辑姓名、生日、
回忆、照片、语音和结尾长信，点击「保存这份心意」，再点「导出礼物」。
把下载的新 HTML 免费交给收礼人；只保存本机内容不会改变公开试玩网址。

进度与内容保存在当前浏览器。换设备或清理网站数据前，请在设置中导出时光备份。
树下独立草稿不混入生日游戏导出；需要发送树信时请保存 PNG 或 TXT。

## 使用许可

可以免费自用、修改、给亲友游玩，也可以免费非商业分享。
禁止商用、转卖、收费下载、收费定制交付和商业推广。

完整条款见随包的 `LICENSE`，版权与项目地址见 `NOTICE`，素材说明见
`THIRD_PARTY_NOTICES.md`。单文件 HTML 也保留完整许可，因此导出的专属礼物
能继续携带声明。玩家自己的照片、语音和原创文字仍归玩家或原权利人。
