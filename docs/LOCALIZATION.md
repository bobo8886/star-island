# 中英双语维护

默认简体中文，首次访问展示语言卡。确认后记住选择；顶部和设置都可重新选择。切换通过重新加载初始化语言相关的场景数据，沿用同一份游戏存档和媒体库。`?language=en` / `?language=zh-CN` 也可指定语言，存储不可用时仍有效。

## 文案

- `src/locales/en.js`：内置中文到英文的翻译表。
- `src/i18n.js`：语言偏好、初始静态页面、模板识别、语言卡及日期。
- 现有模块的 `l10n(...)` 只处理开发者编写的字面量，包括 HTML 模板的静态片段与 Canvas 文本。插入的用户数据依旧经过原有转义，绝不经过全文 DOM 自动翻译。
- `src/personalization.js` 保持 301 个编辑字段及原来的对象 ID、导航与任务条件。保存过的未修改模板可随语言切换；自定义值原样保留。
- 中文旧人物名清理为占位符的模板也会识别。备份和礼物采用现有格式，语言不改变存档键。
- 内置文字翻译不涉及用户的照片、音频或自己写的信。若需要英文录音，作者自行上传对应音频。

新增文本时，在合适的模块使用 `l10n('中文原文')` 并补充翻译表。含变量的文本优先放入叙事注册表，用 `{{recipient}}` 等占位符；只翻译模板，不翻译拼入的用户值。不要翻译路径、ID、样式名或旧存档识别值。新模块需先加载 `i18n.js`，并同步更新单文件打包列表。

## 布局与导出

`language.css` 负责选择卡和英文布局覆盖。日期使用语言相符的格式；英文信纸标题使用 Georgia；烟花优先按英文单词换行。所有图片仍由已有本地 Canvas 逻辑绘制，没有远程翻译、字体或素材服务。

`npm run build` 将双语表、运行逻辑与样式一并写入离线 HTML。赠礼导出移除运行时的选择对话框，接收方打开时重建一份；私人树信草稿仍不会进入礼物。

- 九组核心检查，包括 301 字段无中文遗漏、对象 ID / 任务规则不变、双语模板往返和自定义内容保留。
- 英文真实通关：五段回忆、星座、最终信和 Happy Birthday! 烟花。
- 四区交互、礼物编辑器、许愿树生成及下载英文 PNG。
- 桌面 1440×900、手机 390×844 的选择卡和英文设置。
- 独立离线版、真实导出的礼物及浏览器存储不可用时的语言切换。

开发脚本与生成的测试报告位于 `tests/language-*.py`、`tests/i18n.cjs` 和忽略提交的 `output/language/`。
