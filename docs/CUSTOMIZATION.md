# 个性化与送礼教程

你可以完全通过网页里的 **「星屿礼物工坊」** 制作生日礼物，无需修改代码。6.2 版提供 301 项可编辑内容，涵盖称呼、五段回忆、探索故事、互动台词、地图名称、生日结尾长信和烟花文字。

[返回项目首页](../README.md) · [游玩教程](USER_GUIDE.md)

## 1. 先准备这些内容

可以只改几项，也可以慢慢写完整座岛。第一次制作时，先准备：

- 对方的称呼和你的署名。
- 五段真实回忆，每段先写几句话即可。
- 一封生日长信。
- 一项可以兑现的小心愿，例如一起去郊游、做一顿晚饭。
- 可选：每段回忆一张照片、一段语音，以及一段晚安语音。

默认内容是通用模板；没有填照片和语音也能完整游玩。日期可以留空，不需要为了开始制作而填一个假的生日。

## 2. 打开礼物工坊

先按 [游玩教程](USER_GUIDE.md) 打开离线 HTML 或本地预览，然后选择任一入口：

1. 欢迎页点击 **「制作一份专属礼物」**。
2. 已进入游戏时，点击右上角齿轮，选择 **「布置这座岛 · 留下你的话、照片和语音」**。

工坊有五个分区。电脑端可以一边编辑一边看预览；手机端可用底部 **「预览」** 查看效果。内容多的分区提供 **「选择场景」** 下拉框；也可以使用 **「搜索全部文案」**，输入地点名称、标题或原句的一部分。

搜索时显示匹配的文字字段。要添加照片或语音，请清空搜索，回到对应回忆分组或「声音」分区，媒体选择控件才会显示。

## 3. 第一次制作：跟着这六步做

### 第一步：修改基本信息

在 **「基本信息」** 中填写：

| 字段 | 作用 | 示例 |
| --- | --- | --- |
| 收礼人的称呼 | 信件、祝福和称呼变量中的对方名字 | 小鹿 |
| 赠送者署名 | 生日长信的署名及你的称呼变量 | 朋友 |
| 生日日期 | 可以在文案中引用的自由文字 | 10月8日，或留空 |
| 主角名字 | 可操作的女旅人名称 | 小鹿 |
| 男性旅伴名字 | 同行男角色的名称 | 同行者 |
| 精灵向导名字 | 默认精灵的名称 | 星星 |

还可以修改欢迎页标题、导语和小字。称呼与署名不能为空；没有决定时可以保留默认通用称呼。

生日日期用于展示和文案替换，不会把游戏设置成“只有生日当天才能打开”。修改角色名字也不会改变角色外观；同行外观在游戏的「角色与旅伴」或设置里选择。

### 第二步：写五段回忆

进入 **「五段回忆」**，逐组填写：

1. **回忆主题**：例如初遇、相知、日常、和好、未来；这些主题也会显示在连星谜题中。
2. **标题**：一句简短、有辨识度的话。
3. **地点名称**：回忆页面上展示的地点文案。
4. **正文**：写真实经历，保留换行和分段。
5. 可选的 **照片** 与 **语音**。

例如：

```text
主题：一起散步
标题：那天的晚风，我还记得
地点名称：回家的那条小路

正文：
还记得那次散步吗？

我们没有特意安排去哪里，只是一边走，一边聊一些很小的事。
现在想起那天，我最先记住的还是你的笑。

希望下一段路，也有机会和你一起走。
```

修改地点名称只改变文字，不会移动水晶的位置。五枚水晶的收集顺序自由；观星台连线时按照页面显示的五个主题顺序点击。

### 第三步：修改探索和互动中的话

进入 **「探索与互动」**，按场景选择，或搜索想改的一句：

| 想改哪里 | 在工坊中查找什么 |
| --- | --- |
| 抵达岛屿时的介绍 | 抵达、开场或原介绍中的词句 |
| 篝火聊天 | 篝火及对应的几句话 |
| 树下写信页 | 树下写信页标题、导语、树信默认标题、树信示例正文 |
| 其他地图的故事 | 地图、物件名，或剧情里的原句 |
| 剧情分支 | 该故事的选项文字、选择结果、完成后剧情 |
| 八种活动 | 秋千、沙堡、散步、拍照、种花、纸船、水漂、风车 |
| 地图和地标名称 | 对应地图或地标名 |
| 游戏中的引导提示 | 搜索提示中有辨识度的一段文字 |

这些字段可以改变故事表达，不会修改地图碰撞、物件位置、任务依赖或角色动作。想只保留轻量的生日体验，可以先改主线和八种活动，其他故事以后补完。

### 第四步：写生日结尾长信和兑换券

进入 **「长信与结局」**，修改：

- 盲盒里的长信正文。
- 信件标题、副标题。
- 庆典标题、正文和提示。
- 心愿兑换券的标题、内容。
- 天空烟花文字。

信件署名读取「基本信息」中的赠送者。正文支持分段，右侧或手机预览可以查看信纸排版。

长信示例：

```text
亲爱的{{recipient}}：

今天想认真告诉你，认识你是一件很开心的事。

愿新的一岁，你能靠近喜欢的生活，也有时间休息和发呆。
希望我们以后还能一起发现很多普通却可爱的瞬间。

生日快乐。
```

兑换券示例：

```text
标题：一次由你决定的小旅行

内容：
目的地由你挑，我们一起安排时间。
可以很近，也可以只是去喜欢的公园坐一坐。
```

默认烟花文字是 **「生日快乐!」**。建议使用 4–12 字，让画面上更醒目；字段允许更长文字，但字符越多，单个字能占到的空间越小。烟花在主线完成后出现，大字每 7 秒一轮。

### 第五步：准备声音和旅伴

在 **「声音」** 分区修改晚安留言，选择可选的晚安音频。五段回忆的录音则放在各自回忆分组里。

关闭工坊后，在设置中调整背景音乐、环境与交互、留言语音音量。还可以选择默认的向导精灵、男性旅伴或独自探索。导出的专属礼物会带上当前选择的旅伴外观和三个音量层次。

工坊目前不提供上传替换背景音乐的控件；背景音乐由项目内的 Web Audio 代码生成。

### 第六步：保存、检查、导出

1. 点击底部 **「保存这份心意」**，等页面提示已保存。
2. 返回小岛，打开几段回忆检查文字、照片和语音；也可重新进入工坊查看长信预览。
3. 点击工坊底部 **「导出礼物」**。这个按钮会先保存当前编辑内容，再生成独立 HTML。
4. 也可以在已保存后打开设置，点击 **「导出专属礼物 HTML · 连同照片语音一起带走」**。
5. 下载完成后，用另一个浏览器或独立浏览器会话打开新文件，检查称呼、图片和开场内容。
6. 把这个**新导出的文件**发给对方，或将它作为静态网页首页发布。

导出的游戏会从新的 **0 / 5** 开始，不会把你的通关、支线和活动进度带过去。每次导出都有新的存档标识，因此同一浏览器打开另一份新导出文件，也会是一段新旅程。

## 4. 照片和语音怎么添加

### 回忆照片

1. 在「五段回忆」选择其中一组，清空搜索框。
2. 找到 **「这一段回忆的照片」**，选择本机文件。
3. 支持 PNG、JPG/JPEG、WebP、GIF，单张不超过 **4 MB**。
4. 看到文件已读入的提示后，点击 **「保存这份心意」**。

每段回忆一张照片；重新选择会替换该位置的图片。点击 **「移除」** 后也要保存才会生效。没有照片时，游戏会显示水晶图案。

### 回忆语音与晚安语音

1. 回忆音频放到对应分组的 **「这一段回忆的语音」**。
2. 晚安音频放到「声音」分区的 **「专属晚安语音」**。
3. 单段音频不超过 **8 MB**，选择浏览器能播放的音频文件；上传后实际试听一次。
4. 等文件读入完成，再保存。读入期间保存按钮会暂时不可用。

游戏提供音频文件上传和播放，不包含直接录音按钮。可以先用手机录音工具录好，再把文件传到编辑设备选择上传。

所有照片和语音会进入本地存档，保存时还有总体积限制：编码后的媒体合计不超过约 **40 MB**。如果几份文件都接近单文件上限，可能达到总量限制；可以缩小照片或剪短录音。媒体越大，导出的 HTML 也越大。

## 5. 用变量让名字自动更新

支持变量的文案不必把同一个称呼重复写死。使用两个半角花括号包围变量名：

| 变量 | 替换为 |
| --- | --- |
| `{{recipient}}` | 收礼人的称呼 |
| `{{sender}}` | 赠送者署名 |
| `{{girl}}` | 主角名字 |
| `{{boy}}` | 男性旅伴名字 |
| `{{guide}}` | 精灵向导名字 |
| `{{birthday}}` | 生日日期 |

例如工坊里写：

```text
{{recipient}}，生日快乐！

我是{{guide}}，今天由我带你认识这座岛。
这份礼物来自{{sender}}。
```

设置收礼人「小鹿」、向导「星星」、署名「朋友」后，预览会显示：

```text
小鹿，生日快乐！

我是星星，今天由我带你认识这座岛。
这份礼物来自朋友。
```

生日留空时，`{{birthday}}` 会替换为空文字。预览里如果出现不完整的日期句子，改写那一句或填入日期即可。正文按纯文字呈现，不需要写 HTML 标签。

这些称呼变量用于礼物工坊文案。许愿树中直接写的独立信件使用你输入的文字，不把正文里的花括号变量自动替换成名字。

## 6. 保存、导出和备份有什么区别

| 操作 | 保存了什么 | 用途 |
| --- | --- | --- |
| 工坊「保存这份心意」 | 工坊文字、所选媒体写入当前浏览器 | 在这台设备上继续制作和试玩 |
| 工坊「导出礼物」或设置「导出专属礼物 HTML」 | 个性化文字、照片、语音、旅伴和音量配置；新游戏进度 | 把可玩的生日礼物交给别人 |
| 设置「导出时光备份」 | 当前进度、个性化内容、媒体、设置、树信草稿 | 换设备、留存制作版本、恢复自己的岛 |
| 树信「生成信件图片」 | 当前独立树信的 PNG 排版图片 | 保存到相册，转发给微信好友 |
| 生日结尾「保存信纸」 | 已解锁生日长信的带样式 HTML | 单独阅读、打印或保存为 PDF |

**工坊不是自动保存。** 切换分区、关闭工坊再打开时，本页面会保留编辑草稿；刷新或关闭整个网页会丢弃未保存的工坊草稿。保存成功后才应用到游戏。

**树信自动保存。** 许愿树写信页有独立的本机草稿，也可以主动点「保存草稿」。它不会替换生日结尾长信，也不会混入导出的专属生日游戏。想让朋友看这封树信，需要发送生成的图片或 TXT；想让朋友通关后读到某封信，应将正文写到工坊的「长信与结局」。

工坊中的「树信默认标题」用于新草稿；「树信示例正文」只有玩家主动点击「填入一封示例」时才会填入。修改这些模板不会自动覆盖已经写好的独立树信。

**分享原模板链接不会同步你的本机修改。** 要把定制内容发给对方，需要导出新的礼物文件，再发文件或发布这个新文件。将源码上传到 GitHub 同样不会上传当前浏览器中的存档、媒体或树信。

## 7. 在另一台设备继续制作

1. 在旧设备的设置中点击 **「导出时光备份」**。
2. 把下载的 JSON 文件保管好，传到新设备。
3. 在新设备打开游戏，进入 **「恢复时光备份」**，选择这个 JSON。
4. 确认恢复内容，再点击 **「确认恢复」**。
5. 打开工坊、树信和手记，检查内容已经回来。

恢复会替换当前存档，不是把两份内容合并。先备份目标设备上的现有内容，便于需要时恢复。备份导入上限是 50 MB。

当前版本没有云端账户同步。换浏览器、换网址、清理网站数据或浏览器限制存储，都可能影响本机存档；重要的制作版本应另存 JSON 备份和导出的礼物 HTML。

## 8. 恢复模板或重做另一份礼物

### 恢复通用模板

1. 打开工坊，先导出想保留的旧礼物和完整备份。
2. 点击 **「恢复模板」**。
3. 阅读说明后点击 **「确认恢复模板」**。
4. 此时只替换工坊草稿；检查后点击 **「保存这份心意」** 才真正生效。

保存后，工坊称呼和叙事文字恢复通用模板，已配置的照片和语音会移除。探索进度不会因此清空；独立树信也不是工坊模板的一部分。

### 为另一个人制作

可以在恢复模板后重新填写，也可以保留大部分故事，只修改称呼、照片和具体回忆。为不同的人分别导出礼物文件，并给备份文件起有辨识度的名字，避免混淆。

如果只是想重新游玩当前故事，在设置中使用 **「重新开始这场奇遇」**。它清空探索记录，保留已经保存的个性化内容、媒体、设置和树信。

## 9. 需要改源码时

网页编辑器适合修改故事内容。要改变默认模板、人物动作、场景位置或游戏机制，再修改源码。主要入口如下：

| 文件 | 负责的内容 |
| --- | --- |
| [`src/content.js`](../src/content.js) | 默认称呼、五段回忆、篝火、晚安、生日长信、兑换券 |
| [`src/personalization.js`](../src/personalization.js) | 301 项编辑字段、更多默认场景台词、变量替换 |
| [`src/adventure.js`](../src/adventure.js) | 探索物件、支线与分支故事定义 |
| [`src/activities.js`](../src/activities.js) | 八种活动的定义、名称、位置与介绍 |
| [`src/regions.js`](../src/regions.js) | 地图、地标、通道和区域数据 |
| [`src/game.js`](../src/game.js) | 剧情交互、工坊接入、备份、导出流程 |
| [`src/letter-art.js`](../src/letter-art.js) | 三款树信 PNG 信纸与文字分页 |
| [`src/tree-letter.js`](../src/tree-letter.js) / [`tree-letter.css`](../tree-letter.css) | 树信写作界面与草稿操作 |

操作顺序：

1. 修改源码文件，不要把生成后的大 HTML 当作主要编辑入口。
2. 用 `npm start` 启动开发预览，检查改变是否符合预期。
3. 执行 `npm run build`，重新生成根目录的 `星屿寻迹.html`。
4. 再打开生成的单文件验证，尤其检查照片、信件和导出功能。

开发模式的礼物导出也会使用打包好的单文件作为模板，所以改过源码后，先运行一次 `npm run build` 再导出礼物。

旧浏览器存档中的个性化内容会覆盖新的默认模板。只想检查代码里的新默认内容时，可以先备份现有存档，再用独立浏览器会话打开；不要为了查看模板而直接清掉尚未备份的内容。

## 10. 发给朋友前检查

- 收礼人、署名和生日信息正确，预览中的变量已经替换。
- 五段回忆没有遗漏，照片能打开，语音实际试听过。
- 生日长信与兑换券写的是准备送给对方的内容。
- 已点击保存，并下载了新的专属礼物 HTML。
- 用独立浏览器会话打开导出文件，看到的是新旅程与定制内容。
- 已另存自己的完整时光备份；希望单独发送的树信和纪念照，也已经下载。

完成后，可以发送礼物 HTML 文件，或把导出的 HTML 作为静态网页首页发布。若分享的是树信，直接从微信相册选择 PNG 图片即可。
