# 自由探索剧情与存档契约

三个区域从开始就开放，五枚生日记忆仍是独立主线。新增 14 个物件、3 条可自由决定先后顺序的支线，不要求做完支线才能看到生日结局。

| 支线 | 可以任意顺序拾取的物件 | 送达地点 | 永久纪念与环境变化 |
| --- | --- | --- | --- |
| 让星花再开一次 | 风语花田的星花种子、拾光星屿的铜铃 | 风语花田的花坛 | 星花徽记；花坛持续开花与发光 |
| 寄一封信给明天 | 潮汐回廊的漂流瓶信、白贝壳 | 拾光星屿的邮筒 | 海风邮戳；邮筒亮起回信灯 |
| 补完风的旋律 | 拾光星屿的旧谱页、风语花田的风叶 | 拾光星屿的八音盒 | 晚风乐章；八音盒飘出音符 |

先找到目标时，会留下明确的材料线索。先找到素材也有效；如果拾取素材前已经见过目标，物件文字会回响之前的发现。素材不会在交付后从手记中消失，可持续重读。目标必须到达附近才能完成，背包中的目标按钮仅用于引路。

另外 5 个自由发现为花丛小脚印、树下茶杯、潮汐钟、灯塔石碑和刻度浮木。其中小脚印和潮汐钟提供温和选择，选择结果会保存，重访可以读到同一个结果。完成全部 3 份心愿后，探索背包会出现阿屿的额外便条。

## 交互

- F 为主要互动键，兼容 E；直接触碰未发现的物件也会触发。
- 拾取是首次互动本身：水晶、素材在弹窗打开时就存档，关闭只是继续探索。
- 已发现物件不自动反复弹窗；主动 F 可以重读，或在材料齐全后交付目标。
- 带选择的故事在选定后计为发现，提前离开可稍后继续。
- 地图的区域标签只切换地图视图；点击地点才会进入对应区域并沿小路走过去。

## 状态

```text
state.region = 'home' | 'forest' | 'coast'
state.visitedRegions = 已到访区域 ID[]
state.exploration.found = 已发现物件 ID[]
state.exploration.completed = 已交付任务 ID[]
state.exploration.choices = { fox_trail?: 'wait'|'leave', tide_clock?: 'future'|'today' }
```

旧存档自动补上空探索字段，默认在拾光星屿。反序列化只接受已知物件、区域、任务和选项；只有目标与所需素材均已发现的任务才会保留完成状态。

完整备份保留区域、发现、选择和完成记录。重开清空探索记录、保留用户布置。专属礼物 HTML 不携带试玩进度。
